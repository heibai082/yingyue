## 这是什么

一个给自己用的阅读器：本地 TXT / EPUB 能看，也能用「阅读 3.0」书源联网找书，带桌宠和 AI 助手。

本仓库在原版基础上做了**导入体验**和**换源体验**的改造，方便批量搬书架。

## 与原版的差别

### 导入书架

| 功能 | 说明 |
|---|---|
| 逐本实时进度 | 每开始处理一本就更新「正在处理：书名」，不用等整本跑完 |
| ✅ / ❌ 实时计数 | 状态栏显示成功/失败数量，点 ❌ 直接看失败清单 |
| 单本超时可选 | 15 / 30 / 45 / 60 秒，避免失效书源把整批卡死 |
| 并发数可选 | 2 / 4 / 8 / 12，调大更快但容易被书源限流 |
| 失败清单落盘 | 存在应用私有目录，重开 App 仍在，可「只重试失败的 N 本」 |
| 断点续传 | 已入架的书自动跳过，中断后重新点导入即可继续 |
| **后台导入** | 前台服务保活，切 App / 锁屏都不中断，通知栏显示进度 |
| **失败书进书架** | 书架顶部「⚠ 待搜源 N 本」折叠区，点开可逐本重搜、搜到自动入架 |

### 换源

| 功能 | 说明 |
|---|---|
| 结果缓存 | 打开换源先显示上次结果，不自动重搜；点右上角 ⟳ 才重新联网 |
| 书源黑名单 | 长按任意候选可标记「这个源不行」并写备注，下次自动高亮提醒 |
| 二次确认 | 选中已标记的源时先确认，避免反复点同一个坑 |

## 版本策略

- 正式版之前一律 `0.x`（当前 `0.08`）
- 稳定后才发 `1.0.0`

## 更新下载

App 内「检查更新」走 GitHub Release，安装包优先从自己的 NAS 镜像取；
0.08 起改成**多线程分块**（16 连接）下载：NAS 单连接只有 ~250 KB/s，分块后实测 ~5 MB/s，
60 MB 的包 10 秒左右下完。镜像不支持 Range 时自动退回单流，线路失败自动换下一条。

## 构建

```bash
flutter pub get
flutter build apk --release --target-platform android-arm64 \
  --build-name=0.08 --build-number=8
```

国内网络建议先设镜像：

```bash
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
export PUB_HOSTED_URL=https://pub.flutter-io.cn
```
