# 阅读方向契约（小说 / 漫画通用）

> 起因：0.41 之前，凡是「拿索引当进度、±1 翻章、索引+1 当章号」的地方，在**漫画**
> 上全是反的，用户看到的就是「只剩 35 章没读却显示 3%」「缓存从第 1 话开始下」。
> 这份契约把方向问题收口到一处，**以后新加的书（任何源、任何排序）都直接复用**。

## 目录有两种排序

| 类型 | 首章 | 例 |
| --- | --- | --- |
| 正序（小说） | 第 1 章在最前 | 第1章 … 第1187章 |
| 降序（漫画源） | **最新一话在最前** | 第1187话 … 第1话 |

判断只有一处：`looksNewestFirst(chapters)`（`lib/src/data/models.dart`），
按首尾章号比较，认不出序号时**保守返回 false**（不放乱动老数据）。

## 唯一可用的工具（别再手写）

`lib/src/data/models.dart`

- `readingPosition(chapters, index, local)` —— 阅读顺序上的位置（0 → 全书读完）
- `readingChapterNumber(chapters, index)` —— 「第几章 / 第几话」的显示编号
- `isChapterRead(book, index)` —— 这一章算不算已读
- `Book.progress` / `Book.progressLabel` / `Book.readChars` —— 全部走上面这套

`lib/src/source/chapter_order.dart`（并从 models 转出 `chapterNumber` / `looksNewestFirst`）

- `olderIndex(chapters, index)` / `newerIndex(chapters, index)` —— 阅读顺序上的前后一章
- `olderStep(chapters)` —— 只给需要 ±步长的预取用

## 禁止事项（再出现就是回归）

1. ❌ `progress = index / total` —— 降序目录会得到反的百分比
   → ✅ `readingPosition(...) / total`
2. ❌ `_chapterIndex + 1` / `- 1` 当「下一章 / 上一章」
   → ✅ `newerIndex(...)` / `olderIndex(...)`
3. ❌ `'第 ${index + 1} 章'` 显示章号
   → ✅ `readingChapterNumber(...)`
4. ❌ `index < 当前章` 当「已读」
   → ✅ `isChapterRead(book, index)`
5. ❌ 缓存范围里自己算 `[from..end]` / `[0..from]`
   → ✅ `buildCachePlan(...)`（`lib/src/data/cache_plan.dart`）
