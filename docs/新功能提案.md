| 功能 | 为什么值得 | 工作量 | 风险 |
|---|---|---|---|
| **下载中心（全局队列）** | 现在一次只能缓存一本，离开详情页就看不到进度；做成「任务列表 + 队列 + 暂停/继续 + 失败重试」 | M | 低 |

## 0.48 已落地

- **下载中心**（设置 → 下载中心）：全局队列、串行下载、暂停 / 继续 / 重试 / 清除已完成；
  详情页「开始缓存」与书架「批量缓存」都排进同一个队列。
- **通知栏进度**：队列跑的时候在通知栏显示「缓存《书名》· x/y」，结束自动消失
  （普通通知，不是常驻前台服务；Android 13+ 需要给「嘤阅」开通知权限）。
- **缓存空间页**（设置 → 缓存空间）：每本书占用 / 已缓存章数 / 部分缓存、最后阅读时间；
  支持「导出」「留最近 50 章」「删缓存」。
- **导出已缓存正文**：小说 → `.txt`（按阅读顺序、标注未缓存章）；漫画 → `.cbz`（按话分目录）。
  存到 `Download/嘤阅导出`，拿不到外部存储时退回 App 私有目录。
- **书架批量缓存**：书架右上角「批量管理」→ 选书 → 「批量缓存」，三种范围
  （全部 / 从当前到最新并追更 / 当前往后 50 章）一次排队。
- 新增测试 `test/download_center_test.dart`（7 条：排队/暂停/重试/进度/裁剪/导出）。
